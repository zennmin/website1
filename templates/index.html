The Vault

Every image is sealed with a one-time AES-256 key before it ever touches storage. To open it, a person needs their own RSA private key — sharing means wrapping that same seal for someone new, not handing over a copy.

1

Create an identity

Generates an RSA-2048 key pair for this person — the private key never leaves the vault.

2

Seal an image

The image is encrypted with a fresh AES key the moment it's dropped in.

Drop an image here, or click to choose one
3

Grant access

Re-wraps the same AES key with the recipient's public key — the image itself is never re-encrypted.

4

View a vault

Lists every image this person has been granted a key for.

5

Unlock & view

Unwraps the AES key with this person's private key, then decrypts and verifies the image.
